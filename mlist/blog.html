7. Methodology — how the file was built

Collection: public company records, registries, and directory listings for 2,403 U.S. businesses operating dropshipping / FBA activity.

Cleaning: parse errors fixed, bogus year values cleared, values leaked from other columns corrected, then domain-based deduplication removed 165 duplicates — 2,403 → 2,238.

Verification: domains checked via MX record (dnspython) + HTTP HEAD (requests); emails checked via MX on the host through Google DNS. 80 parallel workers finished in ~6 minutes.

Standardization: 73 raw industry labels mapped to 33 standard categories; the "uncategorized" bucket fell from 1,120 to 91.

Enrichment: social-presence score, outreach-readiness score, and Enterprise / Mid-Market / SMB sizing added to every record.
